# Contributing

Thank you for your interest in contributing to **Wi-Fi Captive Portal Lab**.

This project is intended for education, development, and authorized Wi-Fi laboratory testing.

## Before Contributing

Please make sure your contribution:

- Is intended for authorized networks and devices.
- Does not collect credentials or personal information.
- Does not bypass authentication or access controls.
- Does not intercept HTTPS traffic.
- Does not attempt to control another user's device.
- Does not bypass operating-system volume or security controls.
- Keeps the project suitable for educational use.
